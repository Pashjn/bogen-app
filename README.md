# Bogen-Timer

Offline-Web-App für das iPhone: spielt den Schießablauf nach World Archery ab,
mit festen Regeln wie im Turnier:

- Halle 18 m: 3 Pfeile / 120 s, 2 Probepassen + 20 Wertungspassen
- Freiluft: 6 Pfeile / 240 s, 2 Probepassen + 12 Wertungspassen

Signalhorn (2× / 1× / 3×), Ampelfarben rot – grün – gelb und Countdown.

Installation: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

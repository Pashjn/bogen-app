# Bogen-Timer

Offline-Web-App für das iPhone: spielt den Schießablauf nach World Archery ab
(Halle 18 m: 3 Pfeile / 120 s, Freiluft: 6 Pfeile / 240 s, oder eigene Werte),
mit Signalhorn, Ampelfarben, Countdown, Probepassen und AB/CD-Wechsel.

Installation: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
